# FerdiLegend

Telegram botları, userbot'lar, grup/kanal scraper ve çeşitli tool'lar için hafif ve güçlü Python paketi.

 Geliştirici = FerdiLegend
Şu an geliştirme aşamasında – katkılar hoş geldiniz!

## Özellikler (yakında eklenecek / geliştiriliyor)

- Kolay bot oluşturma ve mesaj gönderme
- Telethon/Pyrogram tabanlı userbot helper'ları
- Grup/kanal üyesi scraper (limitlere dikkat!)
- Flood guard & rate limit yönetimi
- Otomatik yanıt sistemleri
- Session manager (çoklu hesap desteği)
